A Python program that draws a travel poster for VELMORA, the Floating Isles — a place that isn't there — and writes it to /output/entry.png (1024×1024). Pure Python standard library, no network, fully deterministic: a hand-built vector stroke font, procedural gradients, and a hand-rolled PNG encoder. Golden-hour sky, a floating island with a lighthouse and a waterfall pouring into a sea of clouds, a drifting balloon, and smaller islets below.

## Run it

```sh
python3 main.py
```
